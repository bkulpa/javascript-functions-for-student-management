# JavaScript Functions for Student Management

Educational JavaScript project focused on basic functions, arrays and object manipulation.

## Technologies

- JavaScript
- HTML

## Scope

The project contains examples of:

- Basic arithmetic functions with input validation
- Student data stored as JavaScript objects
- Adding students to an array
- Iterating through and displaying student records
- Console-based output

## Usage

Open `index.html` in a browser and use the developer console to view the results.

## Status

Completed educational project. It is no longer actively developed and is kept as part of my JavaScript learning history.
